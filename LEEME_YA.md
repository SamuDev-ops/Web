# Portafolio Convertido - Instrucciones

¡Tu página web ha sido convertida exitosamente a HTML, CSS y JavaScript estándar!

## Archivos Nuevos
- `index.html`: El archivo principal de tu página. Ábrelo directamente en tu navegador.
- `styles.css`: Contiene todos los estilos visuales.
- `script.js`: Maneja las animaciones y el menú móvil.
- `assets/`: Carpeta con tus imágenes (Logo y Hero image).

## Cómo Ver tu Página
Simplemente haz doble clic en el archivo `index.html` en la carpeta `portafolio1`. No necesitas ejecutar `npm run dev` ni ningún servidor.

## Mantenimiento
Para editar la página, simplemente modifica `index.html` (estructura), `styles.css` (diseño) o `script.js` (funcionalidad). No se requieren comandos especiales.

## Solución de Problemas (GitHub)
Si subes la página a GitHub y **las imágenes no cargan**:
1. Asegúrate de que la carpeta `assets` se haya subido correctamente. Deberías verla en la lista de archivos de tu repositorio en GitHub.com.
2. Si no aparece, intenta subirla manualmente arrastrando la carpeta `assets` entera a la página de carga de GitHub.
3. Verifica que los nombres de los archivos en la carpeta `assets` sean exactamente `logo.png` y `hero-image.png` (en minúsculas).
